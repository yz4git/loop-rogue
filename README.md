# Voxel Break Lab

iPhone Safari向けthree.jsボクセル地形破壊アクションゲームです。通常ステージを残したまま、シードから生成するランダムステージを別モードで開始できます。

## 操作

- 左下の仮想スティック：移動
- 右側のドラッグ：三人称カメラを回転
- PUNCH：プレイヤー正面の地形をパンチして破壊
- JUMP：ジャンプ
- 空中PUNCH：地面叩き。着地時に広範囲を破壊し、周囲の敵へダメージ
- 全画面：対応ブラウザでゲーム画面を全画面表示
- リセット：地形を初期状態へ戻す
- ステージ選択：通常ステージ／ランダムステージを切り替え
- ランダムステージ：シードを入力して同じ地形を再生成
- iPhoneでは横画面を推奨
- WebGL非対応環境では`?test=2d`を付けるとCanvas 2Dテスト表示へ切り替え可能
- 2Dテスト表示：矢印キー/WASDで移動、SPACEまたは画面タップで前方を掘削

タッチ操作中はページスクロール、文字範囲選択、長押しメニューを抑制しています。

## 技術構成

- TypeScript / Vite / Vinext Sites
- three.js `WebGLRenderer`
- `Uint8Array`によるボクセル種別・耐久値
- 16×16×16チャンク
- 外面だけをチャンク単位の`BufferGeometry`へ変換
- 破壊時は該当チャンクと境界隣接チャンクだけを再生成
- 1フレームあたりの再生成数を制限
- devicePixelRatioは最大1.5
- 破片・砂煙は固定プールで再利用
- チャンク再生成は1フレームあたり最大2個
- タブ復帰・画面回転時に描画サイズを再同期

## 構成

```text
src/
  core/Settings.ts       設定値
  core/VoxelDemo.ts      three.js初期化、入力、描画ループ
  world/VoxelWorld.ts    TypedArray、チャンク、破壊処理
  world/VoxelDefinitions.ts 素材定義
  stages/StageSource.ts  地形データ供給の共通インターフェース
  stages/HandcraftedStageSource.ts 通常ステージ
  stages/ProceduralStageSource.ts シード付きランダム地形
  worldgen/SeededRandom.ts 決定論的乱数とsalt
  worldgen/Noise.ts 2Dノイズ、FBM、Ridged noise
```

## ランダム生成フェーズ1

- 通常ステージとランダムステージを同じ`VoxelWorld`・チャンク・破壊処理で共有
- シード文字列と生成バージョン1を使用した決定論的生成
- 用途別salt（terrain / hills / ridges / warp / ore）
- 低周波・中周波・高周波の2Dノイズを合成した起伏、尾根、谷、崖
- Domain Warpで地形入力を歪ませ、単純な格子状の丘を回避
- Soil / Rock / Ore / Bedrockの地層
- 外周・底面Bedrock
- 安全な開始足場と深部の暫定ゴール

このフェーズでは洞窟、木、建物、保証ルート、到達可能性検証はまだ実装していません。これらは次のランダム生成フェーズ2以降で追加します。
